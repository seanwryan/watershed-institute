Watershed source vocabulary (Sep 9, 2026)

The StreamWatch Data Dictionary (last updated September 9, 2026) describes these Data Condition tags as currently in use in the raw dataset. Tags may appear alone or combined with semicolons. A full review of Data Condition tags was completed in August 2026.

  • Provisional — Preliminary; has not yet completed final review and may still change.
  • Incomplete — Missing key elements or measurements.
  • Outlier — A value falls well outside the typical range for that parameter or site and has been flagged for review. This does not necessarily mean the value is wrong—only that it warrants a second look before use.
  • Minor Deviation — Small inconsistencies, generally usable as-is.
  • Flagged — Marked for review due to a potential issue; see Notes where available. Flagged records are excluded from analysis under Watershed’s own practice.
  • Corrected — An identified issue has been found and fixed.
  • Erroneous — Contains a physically impossible value (for example pH or conductivity of 0). Unusual but physically possible values are tagged Outlier instead.
  • Duplicate — A repeated entry that does not add new information beyond another record already in the dataset.
  • Duplicate? — Appears to repeat another entry, but this has not yet been confirmed. A bare Duplicate or Duplicate? tag (with no other status) means the pair is still awaiting reconciliation against original paper field sheets—not a signal for which copy to keep.

Codes such as Accepted, Unchecked, Validated, Approved, or Certified may still appear in this application’s lookup lists or older records. The Sep 9 Dictionary does not list them among the tags currently in use in the raw workbook. Prefer the Watershed vocabulary on this page when interpreting source Data Condition wording; use the app-organized lists (Flags / App groups) for codes stored in StreamWatch today.
